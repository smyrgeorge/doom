# Key bindings

This config's own keys; the rest are Doom's (`SPC h b b` lists them all).

| Key | Action |
|---|---|
| `Cmd+B` | Go to the declaration, or list the usages |
| `Option+Enter` | Actions at point: spelling, code actions, Claude |
| `SPC s a` | Search Everywhere |
| `Cmd+Shift+F` | Find in files |
| `Cmd+[` / `Cmd+]` | Back / forward through jumps |
| `M-[` / `M-]` | Previous / next buffer |
| `Cmd+W`, `Cmd+1`..`Cmd+9`, `gt` / `gT` | Close the tab, pick one, next / previous |
| `SPC w SPC` / `SPC w a` | A new tiled pane / arrange the panes |
| `SPC w S` / `SPC w V` | Split, the cursor staying |
| `SPC c ~` | Cycle the word's case style |
| `SPC g d` | The file's git diff in a pane |
| `e` (Magit, on a conflicted file) | Resolve its conflicts |
| `SPC o c` / `SPC o C` | A new Claude Code session / the project's |
| `SPC h T` | Start the profiler / stop it and write the profile |
| `SPC m p` / `SPC m P` (Markdown) | Live preview / in the browser |
| `SPC m d` (PDF, drawing) | Dark pages / canvas |
| `←` / `→`, `zR` / `zM` (sidebar) | Collapse / expand; everything |
| `q` (transient menus) | Close |

PDF, drawing and merge keys: [PDFs](editor.md#pdfs), [Drawings](editor.md#drawings-excalidraw),
[Resolving conflicts](git.md#resolving-conflicts).
